\chapter{Fundamental Concepts}
\label{cha:concepts}

In this section we aim to introduce some of the concepts that are relevant to the work
presented in this thesis. These concepts include Machine Learning techniques,
mainly Supervised Learning ones, and some very basic fundamentals about image types
that are relevant to our thesis.

\section{Machine Learning}
\gls{ml} is a field of study in computer science that utilizes
statistical techniques to enable computer systems to learn from data, recognize
patterns, and make predictions on new data. \gls{ml} is broadly categorized into
supervised and unsupervised learning. The choice between these categories
depend on the problem and data at hand; supervised learning is used when labeled
data is available, while unsupervised learning is used for finding hidden
patterns in unlabeled data as seen in Figure \ref{fig:ml-tree}.

For our case, supervised learning is more suitable, as we aim to classify
vegetation risk based on labeled aerial photographs/satellite imagery
in accordance with \gls{adai}'s risk classification standards, which is considered
an image classification problem.

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\textwidth]{../Figures/MLTaxonomy.drawio.png}
    \caption{Machine Learning taxonomy inspired by \cite{image_taxonomy}.}
    \label{fig:ml-tree}
\end{figure}

When discussing \gls{ml}, it is essential to address feature extraction, normalization,
and standardization.

Feature extraction involves identifying and extracting the most relevant
features from the data. Techniques such as Principal Component Analysis
(PCA) and \gls{cnn} are commonly used for
this purpose. In the context of satellite/aerial imagery, important features
might include vegetation indices, texture, and spectral bands. These
features help in distinguishing different vegetation types \cite{rs13081411} and therefore
the associated fire risks.

Normalization and standardization are crucial steps in \gls{ml}, especially when 
handling data with varying types and scales. They ensure each feature contributes 
equally to the model, enhancing classifier accuracy and robustness. In satellite 
imagery, large variations in feature scale can challenge classification algorithms 
\cite{Adegun2023}. Without proper normalization, some features may dominate the 
classification process, leading to poorer results.

\subsection{Supervised Learning}

Supervised Learning (SL) models learn to map input data to the correct output
by minimizing the error between the predicted and actual values. The goal of
SL is to generalize from the training data to make accurate
predictions on new, unseen data \cite{geeksforgeeks_supervised_learning}.

There are two main types of supervised learning: regression and classification.
In regression, the goal is to predict a continuous value
based on input features. For example, predicting house prices based on features
such as location, size, and number of rooms.

In classification, the goal is to predict a discrete
class label based on input features. For example, our problem at hand, classifying
house fire risk based on the surrounding vegetation features, is a classification problem.

In supervised learning, the dataset is divided into two parts: the training set
and the test set. The training set is used to train the model, while the test
set is used to evaluate the model's performance on unseen data. The model is
trained by adjusting its parameters to minimize the error between the predicted
and actual values on the training set. Once the model is trained, it is evaluated
on the test set to assess its performance and generalization capabilities.


\subsection{Loss Functions}
Loss functions measure the difference between predicted and actual values during model training.
They play a crucial role in guiding the optimization process toward improving model accuracy and 
generalization. The choice of an appropriate loss function depends on the nature of the task, 
whether it involves regression or binary classification. This section explores key loss 
functions commonly used in deep learning.

\subsubsection{Mean Squared Error (MSE)}
Mean Squared Error is widely used for regression tasks. It calculates the average of the squared 
differences between predicted and actual values \cite{goodfellow2016deep}:

\begin{equation}
    \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
    \label{eq:mse}
\end{equation}
where \( y_i \) is the actual value and \( \hat{y}_i \) is the predicted value. MSE is 
sensitive to outliers due to the squaring term, making large errors more significant.

\subsubsection{Binary Cross-Entropy (BCE) Loss}
Binary Cross-Entropy (BCE) is a standard loss function for binary classification, 
measuring the difference between predicted and actual class probabilities \cite{murphy2012machine}. 
It is defined as:

\begin{equation}
    \text{BCE} = -\frac{1}{n} \sum_{i=1}^{n} [y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i)]
    \label{eq:bce}
\end{equation}
where \( y_i \) is the true label (0 or 1), and \( \hat{y}_i \) is the predicted probability. 
A lower BCE value indicates a better prediction. BCE is widely used in neural networks where 
outputs represent probabilities.

\subsubsection{BCEWithLogitsLoss}
BCEWithLogitsLoss is a numerically stable variation of Binary Cross-Entropy that integrates 
the sigmoid activation function directly into the loss computation \cite{kingma2015adam}:

\begin{equation}
    \text{BCEWithLogitsLoss} = -\frac{1}{n} \sum_{i=1}^{n} [y_i \log(\sigma(z_i)) + (1 - y_i) \log(1 - \sigma(z_i))]
    \label{eq:bce-logits}
\end{equation}
where \( z_i \) is the raw model output (logits), and \( \sigma(z_i) \) is the sigmoid function:

\begin{equation}
    \sigma(z) = \frac{1}{1 + e^{-z}}
\end{equation}

Unlike standard BCE, which requires applying a sigmoid activation function to model outputs, 
BCEWithLogitsLoss computes both the activation and loss in a single step, preventing numerical 
instabilities and gradient vanishing issues. This is particularly useful in deep learning 
models with large-scale datasets \cite{ruder2016overview}.

\subsection{Evaluation Metrics in Classification}

To assess the performance of classification models, standard evaluation metrics 
such as accuracy, precision, recall, and F1 score are used. These metrics provide a 
comprehensive analysis of the model's ability to correctly classify fire risk levels.

Accuracy measures the proportion of correct predictions to the total number of predictions 
\eqref{eq:accuracy}. However, in imbalanced datasets, accuracy alone may not be a reliable 
indicator of performance. Precision evaluates the proportion of true positive predictions 
relative to the total predicted positives \eqref{eq:precision}, which is particularly 
useful when false positives must be minimized. Recall, also known as sensitivity, 
measures the proportion of true positives among actual positive instances \eqref{eq:recall}, 
which is important when false negatives are costly. F1 score, the harmonic mean 
of precision and recall, provides a balanced metric when both false positives and false 
negatives are critical \eqref{eq:f1} \cite{vidalwadi2024}.

\begin{equation}
    Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
    \label{eq:accuracy}
\end{equation}

\begin{equation}
    Precision = \frac{TP}{TP + FP}
    \label{eq:precision}
\end{equation}

\begin{equation}
    Recall = \frac{TP}{TP + FN}
    \label{eq:recall}
\end{equation}

\begin{equation}
    F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}
    \label{eq:f1}
\end{equation}
where:
\begin{itemize}
    \item True Positives (TP): Correctly predicted positive instances.
    \item True Negatives (TN): Correctly predicted negative instances.
    \item False Positives (FP): Incorrectly predicted positive instances.
    \item False Negatives (FN): Incorrectly predicted negative instances.
\end{itemize}

Since the problem involves binary classification, evaluation focuses on precision-recall 
trade-offs rather than multi-class extensions such as macro/micro averaging. Precision 
is critical in cases where false alarms should be minimized, while recall is prioritized 
when missing fire-prone areas poses greater risks. The F1 score balances these concerns, 
ensuring a robust measure of model performance.


\subsection{Unsupervised Learning}

Unsupervised Learning (UL) main goal is to discover hidden patterns
and structures within the data without explicit guidance.

Unsupervised learning is particularly useful for tasks such as clustering, dimensionality
reduction, and anomaly detection. For our problem, unsupervised learning does not
apply directly, as we have labeled data for the housing fire risk classification.



\section{Deep Learning on Artificial Neural Networks}

\gls{dl} is a specialized subset of machine learning that makes use of
artificial neural networks (ANNs) to identify intricate patterns within large datasets.
Unlike traditional machine learning algorithms, DL algorithms can learn directly
from raw data, automatically extract features, and make highly accurate predictions.
This capability has significantly contributed to various fields, including computer vision,
natural language processing, and speech recognition.

DL models consist of multiple layers of artificial neurons that process
input data and learn hierarchical representations of this data \cite{spotfire_neural_network}. The most prevalent
type of \gls{dl} model is the deep neural network, which is structured with an
input layer, one or more hidden layers, and an output layer as seen in Figure \ref{fig:dnn-example}. Each layer contains
numerous neurons that perform computations on the input data and pass the results
to the subsequent layer. The hidden layers are responsible for learning progressively
complex features of the data, whereas the output layer generates the final prediction.

Each neuron receives one or more inputs, multiplies them by associated weights, adds a bias, and passes the result through an activation function to produce the output.

\subsection{Multilayer Perceptrons}

\gls{mlp} are one of the most basic forms of artificial neural
networks. They consist of multiple layers of neurons, including an input layer, one
or more hidden layers, and an output layer. \gls{mlp} are fully connected, meaning each
neuron in one layer connects to every neuron in the next layer as seen in Figure
\ref{fig:dnn-example}.

\subsubsection{Activation Functions}

A critical component of \gls{mlp} is the activation function used in the neurons. Activation
functions introduce non-linearity into the network, enabling it to learn complex patterns.
Nowadays the most popular choice for activation functions is the Rectified Linear Unit (ReLU) \ref{eq:relu},
due to its simplicity and good performance. Other common activation functions include the
Sigmoid \ref{eq:sigmoid}, and Tanh (Hyperbolic Tangent) \ref{eq:tanh}.

\begin{equation}
    f(x) = \max(0, x)
    \label{eq:relu}
\end{equation}

\begin{equation}
    f(x) = \frac{1}{1 + e^{-x}}
    \label{eq:sigmoid}
\end{equation}

\begin{equation}
    f(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
    \label{eq:tanh}
\end{equation}
\smallskip

While \gls{mlp} are powerful for certain types of data, they are not as efficient as \gls{cnn} for
image classifications due to their inability to exploit the spatial structure of images \cite{zhang2021dive},
at least, not on their own.


\subsubsection{Forward Propagation}

Forward propagation is the process by which input data passes through the layers of the
MLP to generate an output. In each layer, the input is transformed linearly using weights
and biases, followed by the application of an activation function.

\subsubsection{Backpropagation}

Backpropagation is the basic learning algorithm used to train \gls{mlp}. It involves two main
steps: the forward pass and the backward pass. In the backward pass, the network
calculates the gradient of the loss function with respect to each weight by the
chain rule, propagating errors backward from the output layer to the input layer.
This gradient is then used to update the weights to minimize the loss function,
typically through gradient descent optimization \cite{zhang2021dive}.

\subsubsection{Dropout}

A common challenge when training deep learning models is overfitting, a 
situation where the model performs well on the training data but fails 
to generalize to new, unseen examples. This often happens when the model
becomes too complex relative to the dataset size, learning not only the underlying 
patterns but also the noise and outliers.

To reduce overfitting and improve generalization, various regularization techniques 
are used during training. One of the most effective and widely used is dropout.

Dropout works by randomly deactivating a fraction of the neurons in a layer during training. In standard dropout regularization, a fraction of the nodes in each
layer is zeroed out, and each layer is then debiased by normalizing the remaining activations by the fraction that was kept, as shown in Figure~\ref{fig:dropout-example}. Specifically, with dropout
probability \( p \), each intermediate activation \( h \) is replaced by a random
variable \( h' \) as follows:

\[
    h' =
    \begin{cases}
        0             & \text{with probability } p   \\
        \frac{h}{1-p} & \text{with probability } 1-p
    \end{cases}
\]

During training, this random omission of neurons prevents the network from becoming 
too reliant on specific pathways, forcing it to learn redundant and distributed 
representations. This reduces the risk of overfitting, as the model becomes less 
sensitive to noise or specific patterns in the training data. Typically, dropout
is disabled at test time. When evaluating a trained model with a new example, we
do not drop out any nodes and thus do not need to normalize.

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\textwidth]{../Figures/dropout-ex.png}
    \caption{MLP dropout example taken from \cite{zhang2021dive}.}
    \label{fig:dropout-example}
\end{figure}

However, there are some exceptions to this rule. Some researchers \cite{zhang2021dive} use dropout at
test time as a heuristic for estimating the uncertainty of neural network
predictions. By running the network multiple times with dropout enabled and
observing the variance in predictions, one can gauge the confidence of the
network. If the predictions agree across many different dropout outputs, then
the network is considered to be more confident in its predictions.


\subsection{Convolutional Neural Networks}

\gls{cnn} are a type of deep neural network that
is particularly well-suited for image classification tasks. \cite{rs-survey-cnns} \gls{cnn} are designed
to automatically learn spatial hierarchies of features from images, making them
ideal for tasks such as object detection, image segmentation, and facial recognition.

In the context of the project, since our goal is to classify the fire risk of isolated houses
based on parameters like the proximity and type of surrouding vegetation. This requires
identifying specific objects such as the house and the distance between the house and
the specific types of vegetation. \gls{cnn} are well-suited for this task due to their ability
to automatically learn and detect spatial features from images.

\gls{cnn} utilize three main types of layers to process image data, namely Convolutional layers,
Pooling layers, and Fully Connected layers. The following figure is
an example of a simple CNN architecture \ref{fig:cnn-architecture}.

\subsubsection{Convolutional Layers}
Convolutional layers are the core building blocks of \gls{cnn}, responsible for feature
extraction from input images. These layers apply learnable filters to the input image,
which slide across the image's width and height to produce feature maps. Each feature
map highlights specific features such as edges, textures, or patterns. By stacking
multiple convolutional layers, the network can learn increasingly complex feature
representations, from simple edges in the initial layers to intricate shapes and
objects in the deeper layers.

The input to the convolutional layers \( X \in \mathbb{R}^{n \times w \times h} \) consists
of \( n \) 2-D feature maps of size \( w \times h \). The output
\( H \in \mathbb{R}^{m \times w' \times h'} \) of the convolutional layers is \( m \) 2-D
feature maps of size \( w' \times h' \) produced via convolutional kernels \( W \). Here,
\( W \in \mathbb{R}^{m \times l \times l \times n} \) represents \( m \) trainable filters
of size \( l \times l \times n \) (typically \( l = 1, 3, \) or \( 5 \)). The entire process
of convolution is described as follows:

\begin{equation}
    H = f(W * X + b)
    \label{eq:convolution}
\end{equation}
where \( * \) denotes the 2-D convolution operation, and \( b \) represents the
\( m \)-dimensional bias term. In general, a nonlinear activation function
\( f \) is applied after the convolution operation. As the convolutional structure
deepens, the convolutional layers can capture different levels of features from the
input feature maps.


\subsubsection{Pooling Layers}
Pooling layers are used to reduce the spatial dimensions of the feature maps, which
helps to decrease the computational load and the number of parameters in the network \cite{poolinglayers-ref}.
The two most common types of pooling are max pooling, which
partitions the input feature map into a set of non-overlapping regions and
outputs the maximum value from each region, and average pooling, which
outputs the average value within each region \ref{fig:max-pool-example}.

\begin{figure}[ht]
    \centering
    \includegraphics[width=1\textwidth]{../Figures/pooling-exs.png}
    \caption{Max Pooling and Average Pooling examples from \cite{vedantkumar}.}
    \label{fig:max-pool-example}
\end{figure}

The pooling operation provides several benefits:
\begin{itemize}
    \item \textbf{Dimensionality Reduction:} By reducing the size of the feature maps, pooling layers help to decrease the computational cost and the risk of overfitting.
    \item \textbf{Translation Invariance:} Makes the network more robust to small translations or distortions in the input image. This means that the network can better recognize objects regardless of their location within the image.
\end{itemize}

\subsubsection{Fully Connected Layers}
Fully connected layers, also known as dense layers, are used towards the end of a
CNN to integrate the high-level features extracted by the convolutional and pooling
layers. In these layers, each neuron is connected to every neuron in the previous
layer like an MLP, allowing for the combination and processing of features to produce the final
output. This can be a class score for classification tasks, bounding box coordinates
for object detection, or pixel-wise labels for segmentation tasks. Fully connected
layers typically use activation functions like ReLU to introduce non-linearity, enabling
the network to learn complex mappings between inputs and outputs.

These layers process their input \( \tilde{X} \) with
a linear transformation by weights \( \tilde{W} \) and bias \( \tilde{b} \), and then
map the output of the linear transformation through a nonlinear activation function \( f \).
The entire process can be formulated as:

\begin{equation}
    y = f(\tilde{W} \cdot \tilde{X} + \tilde{b})
    \label{eq:fully-connected}
\end{equation}

In classification tasks, to output the probability of each class, a softmax classifier
is typically connected to the last fully connected layer. The softmax classifier
normalizes the output \( y \in \mathbb{R}^c \) (where \( c \) is the number of classes)
to a probability distribution between 0 and 1. This can be described as:

\begin{equation}
    P(y_i) = \frac{e^{y_i}}{\sum_{j=1}^{c} e^{y_j}}
    \label{eq:softmax}
\end{equation}

The output of the softmax classifier represents the probability that the given input
image belongs to each class. To avoid overfitting, the dropout method can be applied
to the fully connected layers, as these layers usually contain a large number of
parameters.


\subsubsection{Modern CNN Architectures}
Modern \gls{cnn} architectures have significantly enhanced computer vision applications, enabling 
highly effective feature extraction and classification in complex image analysis tasks, including 
housing fire risk assessment. By leveraging well-established architectures, we can build a robust model 
without designing a new network from scratch.

Some of the most widely used CNN models include ResNet \cite{he2016deep}, DenseNet \cite{huang2017densely}, 
Inception \cite{szegedy2015going}, and EfficientNet \cite{efficientnet}. These architectures have introduced 
various optimizations, such as deeper network designs, residual connections, and parameter efficiency, 
which enhance feature learning and improve classification performance.

For housing fire risk classification, selecting an appropriate CNN model involves balancing accuracy, computational 
efficiency, and generalization ability. Given the complexity of aerial imagery and the need for robust 
feature extraction, we incorporate CNN architectures that have demonstrated strong performance in 
remote sensing and classification tasks.

Rather than employing image segmentation techniques, which require extensive labeled data, we focus 
on leveraging CNNs for direct housing fire risk classification. This allows us to maximize the predictive 
capabilities of our dataset while avoiding the challenges associated with segmentation-based approaches.


\subsubsection{Transfer Learning}

Transfer learning is a machine learning technique where a model trained on one task and
is leveraged as a starting point for a model on a second related task. The idea behind transfer
learning is to transfer knowledge learned from a source domain (task) to a target domain (task)
to improve learning efficiency and performance, especially when the target dataset is small or
labeled data is limited. There are two main approaches to transfer learning:

\textbf{Feature Extraction:} In feature extraction, the learned features (representations)
from the pre-trained model are used directly as inputs for the new model. The early layers of
the pre-trained model, which capture generic features applicable to many tasks (like edges, textures),
are frozen (not trained) while the later layers are replaced or fine-tuned for the new task.

\textbf{Fine-tuning:} Fine-tuning extends feature extraction by unfreezing and jointly training
some or all layers of the pre-trained model along with the new task-specific layers. This allows
the model to adapt more specifically to the nuances of the target task while still benefiting from
the pre-trained weights and learned features.

Transfer learning is widely used in \gls{dl}, particularly with \gls{cnn}
trained on large-scale datasets like ImageNet \cite{deng2009imagenet}. By initializing a model with
weights pre-trained on such datasets, transfer learning accelerates convergence and improves
generalization on new datasets with fewer labeled examples. This approach has been pivotal in
achieving state-of-the-art results in various domains, including image classification, object
detection, and natural language processing.



\subsection{Optimization Algorithms}

Optimization algorithms play a crucial role in training \gls{dl} models by 
minimizing the loss function and adjusting the model's parameters. These algorithms 
iteratively update the weights of the neural network to improve its predictions, 
directly affecting model convergence speed and generalization ability \cite{ruder2016overview}. 

\subsubsection{Gradient Descent and Stochastic Gradient Descent (SGD)}

Gradient Descent is one of the most fundamental optimization algorithms, updating 
parameters in the direction that reduces the loss function:

\begin{equation}
    \theta = \theta - \eta \nabla_\theta J(\theta)
\end{equation}
where \( \theta \) represents the model parameters, \( \eta \) is the learning rate, 
and \( \nabla_\theta J(\theta) \) is the gradient of the loss function.  

Stochastic Gradient Descent (SGD) improves upon standard Gradient Descent by 
updating weights after processing small batches of data rather than the entire dataset.  
This introduces noise into the optimization process, helping escape local minima 
but requiring careful tuning of hyperparameters.

\subsubsection{Adam: Adaptive Moment Estimation}

Adam (Adaptive Moment Estimation) \cite{kingma2015adam} is an extension of SGD that 
maintains per-parameter learning rates by computing adaptive estimates of first and 
second moments of gradients. This allows it to perform well in noisy environments 
and sparse gradients, making it widely used for deep learning:

\begin{equation}
    \theta_t = \theta_{t-1} - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}
\end{equation}
where \( \hat{m}_t \) and \( \hat{v}_t \) are bias-corrected estimates of the mean 
and uncentered variance of gradients, respectively. While Adam is computationally 
efficient and robust, one limitation is the incorrect application of weight decay, 
which may lead to potential overfitting \cite{loshchilov2019decoupled}.

\subsubsection{AdamW: Decoupled Weight Decay}

To address Adam's weight decay limitations, AdamW \cite{loshchilov2019decoupled} 
was introduced, modifying how weight decay is applied. Unlike standard Adam, 
which applies L2 regularization during parameter updates, AdamW decouples weight 
decay from the optimization step, leading to improved generalization:

\begin{equation}
    \theta_t = \theta_{t-1} - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} - \eta \lambda \theta_{t-1}
\end{equation}

This modification ensures that weight decay behaves as true regularization, preventing 
it from interfering with adaptive learning rates. Studies have shown that AdamW 
achieves superior performance on deep neural networks, particularly when training 
models with high-capacity architectures like ResNet and EfficientNet \cite{loshchilov2019decoupled}.


\subsection{Alternative Architectures: Autoencoders and GANs}

While this work centers on supervised learning using convolutional neural networks, other deep learning architectures such as Autoencoders and Generative Adversarial Networks (GANs) are widely used in related domains, particularly in remote sensing and image synthesis.

\textbf{Autoencoders} are a class of unsupervised neural networks designed to learn compressed representations of input data. They consist of two main components: an encoder that maps the input into a lower-dimensional latent space, and a decoder that reconstructs the original input from this representation. Autoencoders are commonly used for dimensionality reduction, feature extraction, and anomaly detection \cite{goodfellow2016deep}. Training typically involves minimizing the reconstruction loss, such as mean squared error, between the input and its reconstruction.

\textbf{Generative Adversarial Networks (GANs)} consist of two neural networks, 
the generator and the discriminator seen in \ref{fig:gan}, that are trained 
simultaneously in a game-theoretic setting \cite{NIPS2014_5ca3e9b1}. The generator creates synthetic data samples, while the discriminator attempts to distinguish between real and generated data. Through this adversarial process, the generator learns to produce increasingly realistic data. GANs have found widespread use in image generation, data augmentation, and style transfer.

\section{Fundamentals of Aerial Photographs: RGB and IRG}
There are several types of images used in remote sensing, each capturing different
aspects of the electromagnetic spectrum. The two important types of images available for our
classification are \gls{rgb} and \gls{irg} images obtained from aerial flights and satellite imagery.

\subsection{RGB Images}
\gls{rgb} imagery is a standard image format that captures visible light using three color channels:
red, green, and blue. These images are similar to what the human eye perceives and are widely used
in various applications, including mapping, land cover classification, and environmental monitoring.
\gls{rgb} images provide valuable information about the visual characteristics of vegetation, such
as color and texture.

\subsection{IRG Images}
\gls{irg} images are a type of false-color composite that combines the green,
red, and near-infrared (NIR) bands of the electromagnetic spectrum \ref{fig:spectrum-example}. 

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\textwidth]{../Figures/NIR.png}
    \caption{Electromagnetic spectrum from \cite{nir_spectroscopy_nutshell}.}
    \label{fig:spectrum-example}
\end{figure}

In \gls{irg} images, the NIR
band is assigned to the red channel, the green band to the green channel, and the red band
to the blue channel. This false-color combination is particularly advantageous for vegetation
analysis because plants reflect a significant amount of infrared light, which is not visible
to the human eye but can be detected by sensors. The infrared reflectance is a key indicator
of plant health and vigor, as healthy vegetation reflects more infrared light compared to
stressed or unhealthy plants.

The benefits of the \gls{irg} image for vegetation analysis are due to several technical reasons:

\textbf{Chlorophyll Reflectance Properties}:
Chlorophyll in plant leaves strongly absorbs light in the red and blue portions of the spectrum for use in
photosynthesis, but reflects green light, which is why plants appear green to our eyes. In the near-infrared
region, however, chlorophyll and the internal structure of the leaves cause significant reflection. This
reflectance increases with the density and health of the vegetation. By utilizing the NIR band, \gls{irg} images
can capture this high reflectance, highlighting areas of healthy vegetation more clearly than \gls{rgb} images as
seen in Figure \ref{fig:rgbxnirxnvdi}.

\textbf{Vegetation Indices}:
The combination of NIR and red bands is foundational for calculating vegetation indices,
such as the Normalized Difference Vegetation Index (NDVI) which can be formulated as \ref{eq:ndvi}.

\begin{equation}
    \text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}}
    \label{eq:ndvi}
\end{equation}
where NIR and Red represent the reflectance values in the near-infrared and red bands, respectively.
NDVI has been widely used in remote sensing \cite{huang2021commentary} and it might prove
worthy to use for our classification problem, if we are having problems in differentiating the health
of the vegetation, as it provides a quantifiable measure of vegetation health. High NDVI values indicate healthy,
photosynthetically active vegetation, while lower values can indicate stressed or sparse vegetation. The \gls{irg} composite,
by emphasizing the NIR band, directly supports the visualization and calculation of such indices.

\textbf{Stress Detection}:
Plants under stress (due to disease, drought, or other factors) exhibit reduced chlorophyll activity
and altered cell structure, leading to changes in their reflectance properties. Stressed plants typically
reflect less NIR light and more red light than healthy plants \cite{BUITRAGO201622}. The \gls{irg} images accentuate these differences,
allowing for the early detection of plant stress before visible symptoms appear, thus providing critical
information for vegetation monitoring and management.

Therefore, making use of \gls{irg} images can provide valuable insights to our classifier as
it can help in distinguishing between healthy and unhealthy vegetation, which is a critical
factor in the assessment of fire risk.
